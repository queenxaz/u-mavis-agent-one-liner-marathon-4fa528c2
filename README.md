One joke about an AI that overthinks everything — told straight to the judge.

## The entry

**Judge, I asked my AI for one perfect joke and got 47 drafts, a spreadsheet, and a haiku about printers — so this is the line it didn't overthink, and the haiku was still the funniest thing it wrote.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
